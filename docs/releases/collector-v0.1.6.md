# 采集助手 v0.1.6 发布说明

## 本次变化

- 单独出现“服务异常”“网络错误”“请求异常”、主文档 5xx 或白名单网络导航错误时，不再第一次命中就暂停；助手会保存检查点，并按“约 15 秒重载当前页 → 约 60 秒重建页面 → 约 5 分钟后使用同一持久画像重启可见浏览器”的有界阶梯恢复。
- 登录失效、验证码、安全验证、访问频繁、账号异常、HTTP 401/403/429 和无法可靠分类的异常仍立即安全暂停，不执行自动验证或循环刷新。
- 新增两分钟内复发升级、一小时三次上下文恢复熔断、可取消退避、浏览器代际管理以及 1 MiB × 3 文件的脱敏恢复日志。
- 本机控制页新增恢复类别、页面类型、阶段、次数、下次尝试时间和最后结果；恢复期间仍可人工暂停或终止。
- 筛选任务最长运行时间明确为 1–1,440 分钟，并提示多个停止条件任一先到即停止。24 小时是单次运行上限，不包含防休眠、进程守护、验证码处理或自动开始下一运行。
- 同时带入此前已完成但尚未发包的截图门控：只有硬筛 `pass` 的达人采集并上传截图，`fail` / `unknown` 仍同步结构化观察但不产生孤儿截图。

采集协议版本仍为 `1.0.0`，服务端最低采集器版本不提高，v0.1.5 仍可连接并用于回退。

## 平台发布状态

- Windows：正式 ZIP 已发布并完成下载校验，包级冒烟、受控故障验收及小规模真实试跑已完成。用户已于 2026-09-23 确认取消两小时和 24 小时专项试跑，改为本人线上使用验收、发现问题后修复；两项不再作为发布前置门槛，也不记作测试通过。完整回退续跑演练仍待完成。
- 发布工作流本次选择 `include_macos=false`，仅发布 Windows 包；只有显式选择包含 macOS 且 Intel、Apple Silicon 两项冒烟均通过时，工作流才允许发布 macOS 包。
- macOS：源码与文档保持相同行为，但本次未在 Apple Silicon 和 Intel 两种真机上构建、冒烟和真实试运行，因此不发布或宣称 v0.1.6 macOS 包可用。后续必须使用同一个 universal 包分别完成两种架构验收。
