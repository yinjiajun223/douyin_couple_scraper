# 采集助手 v0.1.7 本机诊断包

## 本次范围

针对“未能安全归类的错误”暂停后原始故障线索丢失的问题，新增仅在本机保存的脱敏错误历史。此前真实暂停已被用户继续，旧版本没有留下可用错误详情，尚不能确认根因是网络、浏览器还是平台限制；本次不宣称已修复该暂停根因。

- 控制页标题显示实际助手版本；底部“最近错误诊断”显示时间、运行 ID、出错步骤、错误类型、白名单错误码、HTTP 状态及精简代码位置。
- 继续运行和重启不清空历史，页面最多展示最近 20 条。错误记录位于共享 `data/diagnostics/errors.jsonl`，连同 `.1`、`.2` 最多 3 个 1 MiB 文件，自动轮换，与原恢复日志分别限额。
- 不保存原始错误消息、完整堆栈、Cookie、令牌、页面正文或完整网址；诊断不上传服务器。文件读写失败会提示，且不阻止原有安全暂停。
- 原有人工开始、未知异常暂停、验证码与明确平台限制暂停规则不变；不调整重试次数、采集速度、服务端最低版本或采集协议。

## 切换方式

将 ZIP 解压到现有 v0.1.6 目录的同级，复用原 `../data`；不要覆盖旧目录。人工暂停并确认待同步数据处理好后，关闭旧助手和其采集浏览器，再双击新目录的 `start-collector.cmd`。控制页标题应显示 v0.1.7，核对原配对和画像后人工继续。不要删除或外传共享数据目录。下一次报错时，截图“最近错误诊断”供排查；旧版本未保存的报错无法补录。
