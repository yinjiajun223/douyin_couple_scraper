# Collector v0.1.11

## 变更摘要

- 单个作者页在重载、重建核验页和同画像重启浏览器后仍为暂时性“服务异常”时，只跳过当前作者并继续，不生成观察、批次、候选或截图。控制页显示累计“故障跳过”和最近固定原因；跳过代表没有取得可信数据，会降低本轮召回率，不代表作者不符合条件。
- 推荐流暂时故障经历完整恢复仍失败时进入可取消的指数冷却，间隔封顶后开启下一恢复周期，不再因固定恢复预算耗尽整场暂停。
- 已持久化批次的网络、超时或 5xx 失败按队列 `nextAttemptAt` 持续重试；截图上传的网络、超时或 5xx 同样保留本机截图并退避重试。等待期间停止翻页，人工暂停和终止仍有效。
- 设备撤销、HTTP 401/403/429、升级要求、业务批次拒绝、无效签名地址、登录失效、验证码、访问频繁、账号异常、未知错误和本地检查点/队列写盘失败仍安全暂停，不自动绕过。
- 带入 Windows 队列原子替换遇到 EPERM/EACCES/EBUSY 的有界短重试，并清理失败的临时文件。

采集协议仍为 `1.0.0`，服务端最低采集器版本不提高。

- Windows 正式 ZIP 已生成：`artifacts/collector-windows-v0.1.11.zip`，44,303,274 字节；包级冒烟和 `start-collector.cmd` 启动器冒烟通过，内置 Node、DPAPI 配对往返、独立画像、可见 Chrome、本机控制服务和公开 CA 均通过检查。

## 安装与回退

先人工暂停旧运行并确认待同步数据状态，关闭旧助手和其可见 Chrome。将新包解压到旧版本同级的新目录，继续复用 `../data`，不要覆盖旧目录或复制 DPAPI/Keychain 令牌。验证完成前保留 v0.1.10 目录；需要回退时先关闭 v0.1.11，再从旧目录启动并人工继续。
